# 阅读查词

Android TV 1.1.0 支持鼠标左键点英文单词，也支持确认键进入选词、方向键移动、再次确认查询。浮层仅显示原词、必要时的词形原形及中文释义；点击外部、返回或确认可收起。长释义可用鼠标滚动；浮窗内按方向键会收起浮窗并移动选词光标。失败时点击浮层或确认重试，沿用原请求标识。

纯文本与 XHTML 共用 `WordLookupRequest`，包含 bookId、pageNumber、word、context、selectionStart（UTF-16）和 requestId。`POST /api/tv/word-lookup` 使用设备凭证并验证儿童对书籍的授权，儿童与书名从服务端取值。阅读计时与服务端防沉迷规则继续生效。

阅读服务器配置 `WORDLEARNING_API_URL`（HTTPS `/api` 地址，隔离测试可用 loopback HTTP）和 `WORDLEARNING_INTEGRATION_KEY`。wordlearning 配置相同的 `READBOOK_INTEGRATION_KEY` 及 JSON 格式的 `READBOOK_USER_MAP`，将阅读儿童 ID 映射至有效学生 ID；真实值仅保存在受保护部署配置中。集成凭证不下发电视。

wordlearning 优先查询原有词库，缺词查询固定 HTTPS 网络词典并存入共享“读书词库”；后台词条等级筛选中的读书词库是独立类别，不是新的 RAZ 难度。人物姓名使用独立人名缓存，绝不写入词库、个人候选、查询流水或学习记录。语境判断单独缓存；相同语境不重复调用模型，新语境仍需消除 Will/May 等歧义。

普通词逐次查询保存原词、上下文、书名、页码及时间，并聚合为本人候选；网络重试不增加次数。背单词网页“学习统计”可查看候选和流水。已有教学词库 ID 的新词在原学习范围及预算内优先考虑；只有网络释义的词先保存在读书词库候选，不能凭空生成答题选项。查询不改变积分、答题次数、正确率、记忆或正在作答的词单。

验证命令：

```sh
cd server
npm test -- --runInBand
npm run build
cd ../tv-app
./gradlew testDebugUnitTest
```

设备测试只用于独立测试 AVD：先运行 `node tv-app/scripts/word-lookup-device-fixture.cjs`，用 loopback 测试地址构建 Debug/AndroidTest，通过指定 serial 的 `adb reverse tcp:8896 tcp:8896` 连到隔离接口。运行 `ReaderWordLookupDeviceTest` 验证纯文本/XHTML、鼠标主键与副键、遥控器、重试、迟到响应和外部点击。可选的真实书籍 JSON 放在测试应用私有 `files/qa-treehouse.json`，不纳入提交。测试包的 loopback 地址不得用于发布。

浮层视觉依据本次 Azure image2.5 设计稿，用 Android 原生字体和矢量背景实现，无图片文字。正式发布须沿用旧版本证书，在 Release/R8 后验证查词和正文显示。


本轮验收：阅读服务85项测试、TV 69项JVM测试、wordlearning 77项相关测试与3项网页测试通过；独立TV实例4项Debug设备测试覆盖真实《神奇树屋》文本。Release应用单独启动、同步、阅读与遥控器查词通过；Release instrumentation运行器存在测试包desugar类冲突，本轮未将其记为通过，也未为测试运行器修改生产保留规则。最终发布包使用正式服务地址、原有商店证书，非Debug。线上人名缓存首查约4秒、再次约16毫秒，个人流水/候选/词库均未新增人名。蓝牙鼠标尚未实际配对，左键与副键以Android鼠标来源事件完成验证。


1.1.1追加修复：用户现有AndroidTV仍使用Room版本1，章节索引缺失导致升级退出；设备服务端绑定也已失效。版本4迁移补齐索引，保留数据；启动时对原token限时重新登记，明确无绑定时进入绑定流程。已备份用户本地数据库并恢复其康宁绑定，真实同步9本书与已有进度通过，随后用同签名Release覆盖。新迁移设备测试覆盖1/2/3三个旧版本，原JVM测试69项通过；修复包versionCode为8。


1.1.2：上下键改为上一/下一实际排版行，尽量保留横向位置，左右键仍逐词；XHTML上下换行不会跳到另一栏。查词响应不再等待AI，直接读主词库/读书词库/已有缓存，缺词才查网络。后台持久任务负责姓名排除、原始查看时间、普通词候选与重试，姓名只保留独立缓存；API可能先返回processing，但释义立即展示。


1.1.3：点击单词或遥控器确认时并行请求中文释义和 `/api/tv/word-audio`。发音经同源服务代理取得wordlearning对应英文录音，校验原词、MP3类型与SHA-256；没有既有录音的词形使用wordlearning同一英文TTS服务并独立缓存，不用原形录音替代。`ReaderWordAudioPlayer` 每次只播放一个词，切词、方向键收起浮窗、离开阅读页会取消迟到响应、停止播放并释放临时音频文件，不改系统音量。

浮窗出现后的四方向键统一先收起浮窗，再执行上下换行或左右逐词；无需先按返回。最高级等联网查询词形，即使候选词归并为已有原形，也单独缓存本次网络释义以免下次重复联网。


1.1.4修复连续查词后的浮窗卡顿：通过实际小米遥控器相同注入路径复现，方向键已送达，但主线程在 `MediaPlayer.release()` 停顿约2.5秒。现在每次发音的播放器操作和清理由独立线程持有，浮窗先收起，停止操作不等待底层释放；旧音频焦点和文件也不影响新发音。新增完整播放后反复换词与慢释放压力测试，不修改遥控器桥接或音量配置。
